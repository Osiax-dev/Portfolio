DÉPLOIEMENT SUR NETLIFY (gratuit)
───────────────────────────────────
  1. Va sur https://app.netlify.com
  2. Clique "Add new site" → "Deploy manually"
  3. Glisse-dépose le dossier entier du portfolio
  4. Ton site est en ligne en 30 secondes !

RECEVOIR LES EMAILS DU FORMULAIRE
───────────────────────────────────
  Après déploiement :
  1. Dans Netlify → ton site → "Forms"
  2. Tu verras le formulaire "contact"
  3. Va dans "Form notifications"
  4. Ajoute ton email : osiaxdev899@gmail.com
  5. Tu recevras chaque message directement !
